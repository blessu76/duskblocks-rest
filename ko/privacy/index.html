시행일: 2026-11-14 · 운영자: Davy Kim (ipe Studio)

1. 수집하는 정보

Dusk Blocks(이하 "앱")은 개인 개발자 Davy Kim (ipe Studio)가 운영하는 모바일 게임입니다. 앱에는 계정·로그인이 없으며, 이름·이메일·연락처·위치·기기 식별자 등 개인정보를 수집하거나 서버로 보내지 않습니다.

게임 진행, 점수, 설정은 사용자의 기기에 저장되며, 앱을 삭제하면 함께 삭제됩니다. iCloud 동기화를 사용하는 경우 게임 진행 저장은 사용자 본인의 iCloud에도 보관됩니다(아래 참고). 게임은 인터넷 연결 없이 동작합니다.

앱에는 광고·분석·추적 SDK가 없습니다.

iCloud 동기화(iOS). 같은 Apple ID로 로그인한 다른 기기에서도 이어서 플레이할 수 있도록, iOS 앱은 게임 진행 저장을 사용자 본인의 iCloud(iCloud 키-값 저장소)에 보관하고 기기 간에 동기화합니다. 이 데이터는 사용자의 iCloud 계정에 보관되며 회사 서버로 전송하지 않습니다. 회사는 이 데이터를 볼 수 없습니다. 앱 또는 기기에서 iCloud를 끄면 게임 진행 저장은 해당 기기에만 남습니다.

2. 웹사이트

이 웹사이트(duskblocks.ipe.rest)는 정적 사이트입니다. 분석 도구를 쓰지 않고 쿠키도 설정하지 않습니다. 언어를 선택하면 브라우저가 그 선택을 사용자의 기기에만 기억할 수 있으며, 우리에게 전송되지 않습니다. 페이지는 기기에 있는 글꼴을 사용합니다. 사이트는 GitHub Pages에서 호스팅되며, GitHub이 자체 정책에 따라 일반적인 웹 요청 정보(예: IP 주소)를 처리할 수 있습니다.

3. 제3자

사용자의 정보를 판매하지 않으며 누구와도 공유하지 않습니다. 앱이 출시되면 다운로드는 각 앱 스토어가 자체 개인정보 처리방침에 따라 처리합니다.

4. 문의와 이용자의 권리

개인정보의 열람·정정·삭제·처리정지를 요청하거나 궁금한 점이 있으면 ipe.haven@gmail.com로 메일을 보내 주세요. 앱과 웹사이트가 개인정보를 수집하지 않으므로 보통 찾아볼 정보가 없으며, 이메일로 주고받은 내용은 찾아서 삭제할 수 있습니다.

5. 아동

앱은 만 16세 미만(또는 거주 지역의 최소 연령 미만) 아동을 대상으로 하지 않으며, 어떤 이용자로부터도 개인정보를 수집하지 않습니다.
