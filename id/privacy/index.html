Kebijakan Privasi

2026-11-16

Singkatnya: aplikasi Dusk Blocks tidak mengumpulkan informasi pribadi dan tidak berisi analitik maupun iklan. Situs web ini adalah situs statis tanpa analitik dan tanpa cookie, serta tidak meminta nama, email, atau akun.

Tanggal berlaku: 2026-11-14 · Operator: Davy Kim (ipe Studio)

1. Informasi yang kami kumpulkan

Dusk Blocks ("Aplikasi") adalah game seluler yang dioperasikan oleh pengembang perorangan, Davy Kim (ipe Studio). Aplikasi tidak memiliki akun atau proses masuk, dan tidak mengumpulkan maupun mengirim ke server mana pun informasi pribadi seperti nama, email, detail kontak, lokasi, atau pengenal perangkat.

Kemajuan permainan, skor, dan pengaturanmu disimpan di perangkatmu dan ikut terhapus saat kamu menghapus Aplikasi. Jika memakai sinkronisasi iCloud, kemajuan permainanmu juga disimpan di iCloud milikmu sendiri (lihat di bawah). Permainan ini berjalan tanpa koneksi internet.

Aplikasi tidak berisi iklan, analitik, maupun SDK pelacakan.

Sinkronisasi iCloud (iOS). Agar kamu tetap bisa bermain di perangkat lain yang masuk dengan Apple ID yang sama, Aplikasi iOS menyimpan kemajuan permainanmu di iCloud milikmu sendiri dan menyinkronkannya antarperangkatmu. Data ini disimpan di akun iCloud-mu dan tidak dikirim kepada kami atau server mana pun yang kami kelola; kami tidak dapat melihatnya. Jika kamu mematikan iCloud untuk Aplikasi (atau perangkat), kemajuanmu hanya tersimpan di perangkat tersebut.

2. Situs web

Situs web ini (duskblocks.ipe.rest) adalah situs statis. Situs ini tidak memakai alat analitik dan tidak menyetel cookie. Jika kamu memilih bahasa, browsermu mungkin menyimpan pilihan itu hanya di perangkatmu sendiri; pilihan itu tidak pernah dikirim kepada kami. Halaman memakai font bawaan perangkatmu. Situs ini di-host di GitHub Pages, yang dapat memproses informasi permintaan web biasa (seperti alamat IP-mu) sesuai kebijakan GitHub sendiri.

3. Pihak ketiga

Kami tidak menjual informasimu dan tidak membagikannya kepada siapa pun. Saat Aplikasi dirilis, pengunduhan akan ditangani oleh toko aplikasi sesuai kebijakan privasi mereka masing-masing.

4. Pertanyaan dan hakmu

Untuk meminta akses, koreksi, penghapusan, atau penghentian pemrosesan informasi pribadimu, atau untuk mengajukan pertanyaan apa pun, tulislah ke ipe.haven@gmail.com. Karena Aplikasi dan situs web tidak mengumpulkan informasi pribadi, biasanya kami tidak menyimpan apa pun untuk dicari; korespondensi email dapat kami cari dan hapus.

5. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 16 tahun (atau usia minimum di wilayahmu), dan Aplikasi tidak mengumpulkan informasi pribadi dari pengguna mana pun.
