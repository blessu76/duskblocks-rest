隱私權政策

2026-11-16

簡而言之： Dusk Blocks 應用程式不蒐集任何個人資料，也不含任何數據分析或廣告。本網站為靜態網站，沒有數據分析、不使用 Cookie，也不會要求你提供姓名、電子郵件或帳號。

生效日期：2026-11-14 · 營運者：Davy Kim (ipe Studio)

1. 我們蒐集的資料

Dusk Blocks（以下稱「本應用程式」）是由個人開發者 Davy Kim (ipe Studio) 營運的行動遊戲。本應用程式沒有帳號或登入功能，也不會蒐集你的姓名、電子郵件、聯絡方式、位置或裝置識別碼等任何個人資料，更不會將這些資料傳送到任何伺服器。

遊戲進度、分數與設定儲存在你的裝置上，刪除 App 時會一併刪除。使用 iCloud 同步時，遊戲進度也會保存在你自己的 iCloud 中（見下文）。遊戲不需要網路連線即可運作。

本應用程式不含任何廣告、數據分析或追蹤用的 SDK。

iCloud 同步（iOS）。 為了讓你在以相同 Apple ID 登入的其他裝置上繼續遊戲，iOS 版本應用程式會將遊戲進度儲存在你自己的 iCloud 中，並在你的裝置之間同步。這些資料保存在你的 iCloud 帳號內，不會傳送給我們或我們營運的任何伺服器，我們也無法查看。若你在本應用程式（或裝置）中關閉 iCloud，遊戲進度將只保存在該裝置上。

2. 本網站

本網站（duskblocks.ipe.rest）是靜態網站，不使用任何數據分析工具，也不會設定 Cookie。若你選擇語言，瀏覽器可能會把這個選擇保留在你自己的裝置上，絕不會傳送給我們。頁面使用你裝置內建的字型。本網站託管於 GitHub Pages，GitHub 可能會依其自身政策處理一般的網頁請求資訊（例如你的 IP 位址）。

3. 第三方

我們不會出售你的資訊，也不會與任何人分享。本應用程式上架後，下載將由各應用程式商店依其自身的隱私權政策處理。

4. 疑問與你的權利

如需請求查閱、更正、刪除個人資料或停止處理，或有任何疑問，請來信至 ipe.haven@gmail.com。由於本應用程式與本網站不蒐集個人資料，我們通常沒有可供查詢的資料；不過電子郵件往來紀錄，我們可以找出並刪除。

5. 兒童

本應用程式不以 16 歲以下（或你所在地區最低年齡以下）的兒童為對象，而且不會蒐集任何使用者的個人資料。
