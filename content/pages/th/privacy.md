**สรุปสั้นๆ:** แอป Dusk Blocks ไม่เก็บข้อมูลส่วนบุคคลใดๆ และไม่มีการวิเคราะห์ข้อมูลหรือโฆษณา เว็บไซต์นี้เป็นเว็บแบบสถิตที่ไม่มีการวิเคราะห์ข้อมูลและไม่มีคุกกี้ และไม่ขอชื่อ อีเมล หรือบัญชี

## 1. ข้อมูลที่เราเก็บรวบรวม

Dusk Blocks ("แอป") เป็นเกมมือถือที่ดำเนินงานโดยนักพัฒนารายบุคคล คือ {{OPERATOR}} แอปไม่มีบัญชีหรือการลงชื่อเข้าใช้ และไม่เก็บรวบรวมหรือส่งข้อมูลส่วนบุคคลใดๆ ไปยังเซิร์ฟเวอร์ใดๆ เช่น ชื่อ อีเมล ข้อมูลติดต่อ ตำแหน่งที่ตั้ง หรือรหัสประจำอุปกรณ์

ความคืบหน้าของเกม คะแนน และการตั้งค่าจะถูกเก็บไว้ในอุปกรณ์ของคุณ และจะถูกลบไปเมื่อคุณลบแอป หากใช้การซิงก์ iCloud ความคืบหน้าของเกมจะถูกเก็บไว้ใน iCloud ของคุณด้วย (ดูด้านล่าง) เกมทำงานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

แอปไม่มีโฆษณา การวิเคราะห์ข้อมูล หรือ SDK สำหรับติดตามใดๆ

**การซิงก์ iCloud (iOS)** เพื่อให้คุณเล่นต่อบนอุปกรณ์อื่นที่ลงชื่อเข้าใช้ด้วย Apple ID เดียวกันได้ แอป iOS จะเก็บความคืบหน้าของเกมไว้ใน iCloud ของคุณเอง และซิงก์ระหว่างอุปกรณ์ของคุณ ข้อมูลนี้เก็บไว้ในบัญชี iCloud ของคุณ ไม่ถูกส่งมาให้เราหรือเซิร์ฟเวอร์ใดๆ ที่เราดำเนินการ และเราไม่สามารถดูได้ หากคุณปิด iCloud สำหรับแอป (หรืออุปกรณ์) ความคืบหน้าจะถูกเก็บไว้ในอุปกรณ์นั้นเท่านั้น

## 2. เว็บไซต์

เว็บไซต์นี้ (duskblocks.ipe.rest) เป็นเว็บแบบสถิต ไม่ใช้เครื่องมือวิเคราะห์ข้อมูลและไม่ตั้งค่าคุกกี้ หากคุณเลือกภาษา เบราว์เซอร์ของคุณอาจจำตัวเลือกนั้นไว้ในอุปกรณ์ของคุณเองเท่านั้น และจะไม่ถูกส่งมาถึงเรา หน้าเว็บใช้ฟอนต์ของอุปกรณ์คุณเอง เว็บไซต์โฮสต์อยู่บน GitHub Pages ซึ่งอาจประมวลผลข้อมูลคำขอเว็บทั่วไป (เช่น ที่อยู่ IP ของคุณ) ตามนโยบายของ GitHub เอง

## 3. บุคคลที่สาม

เราไม่ขายข้อมูลของคุณและไม่แบ่งปันให้ผู้ใด เมื่อแอปเปิดตัวแล้ว การดาวน์โหลดจะดำเนินการโดยร้านแอปตามนโยบายความเป็นส่วนตัวของร้านเหล่านั้นเอง

## 4. คำถามและสิทธิ์ของคุณ

หากต้องการขอเข้าถึง แก้ไข ลบ หรือระงับการประมวลผลข้อมูลส่วนบุคคลของคุณ หรือมีคำถามใดๆ โปรดเขียนมาที่ [{{EMAIL}}](mailto:{{EMAIL}}) เนื่องจากแอปและเว็บไซต์ไม่เก็บข้อมูลส่วนบุคคล โดยปกติเราจึงไม่มีข้อมูลที่ต้องค้นหา ส่วนอีเมลที่ติดต่อกันนั้น เราสามารถค้นหาและลบได้

## 5. เด็ก

แอปไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 16 ปี (หรือต่ำกว่าอายุขั้นต่ำในภูมิภาคของคุณ) และแอปไม่เก็บข้อมูลส่วนบุคคลจากผู้ใช้คนใดเลย
