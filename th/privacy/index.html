นโยบายความเป็นส่วนตัว

2026-11-14

สรุปสั้นๆ: แอป Dusk Blocks ไม่เก็บข้อมูลส่วนบุคคลใดๆ และไม่มีการวิเคราะห์ข้อมูลหรือโฆษณา เว็บไซต์นี้เป็นเว็บแบบสถิตที่ไม่มีการวิเคราะห์ข้อมูลและไม่มีคุกกี้ และไม่ขอชื่อ อีเมล หรือบัญชี

วันที่มีผลบังคับใช้: 2026-11-14 · ผู้ให้บริการ: Davy Kim (ipe Studio)

1. ข้อมูลที่เราเก็บรวบรวม

Dusk Blocks ("แอป") เป็นเกมมือถือที่ดำเนินงานโดยนักพัฒนารายบุคคล คือ Davy Kim (ipe Studio) แอปไม่มีบัญชีหรือการลงชื่อเข้าใช้ และไม่เก็บรวบรวมหรือส่งข้อมูลส่วนบุคคลใดๆ ไปยังเซิร์ฟเวอร์ใดๆ เช่น ชื่อ อีเมล ข้อมูลติดต่อ ตำแหน่งที่ตั้ง หรือรหัสประจำอุปกรณ์

ความคืบหน้าของเกม คะแนน และการตั้งค่าจะถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น และจะถูกลบไปเมื่อคุณลบแอป เกมทำงานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

แอปไม่มีโฆษณา การวิเคราะห์ข้อมูล หรือ SDK สำหรับติดตามใดๆ

2. เว็บไซต์

เว็บไซต์นี้ (duskblocks.ipe.rest) เป็นเว็บแบบสถิต ไม่ใช้เครื่องมือวิเคราะห์ข้อมูลและไม่ตั้งค่าคุกกี้ หากคุณเลือกภาษา เบราว์เซอร์ของคุณอาจจำตัวเลือกนั้นไว้ในอุปกรณ์ของคุณเองเท่านั้น และจะไม่ถูกส่งมาถึงเรา หน้าเว็บใช้ฟอนต์ของอุปกรณ์คุณเอง เว็บไซต์โฮสต์อยู่บน GitHub Pages ซึ่งอาจประมวลผลข้อมูลคำขอเว็บทั่วไป (เช่น ที่อยู่ IP ของคุณ) ตามนโยบายของ GitHub เอง

3. บุคคลที่สาม

เราไม่ขายข้อมูลของคุณและไม่แบ่งปันให้ผู้ใด เมื่อแอปเปิดตัวแล้ว การดาวน์โหลดจะดำเนินการโดยร้านแอปตามนโยบายความเป็นส่วนตัวของร้านเหล่านั้นเอง

4. คำถามและสิทธิ์ของคุณ

หากต้องการขอเข้าถึง แก้ไข ลบ หรือระงับการประมวลผลข้อมูลส่วนบุคคลของคุณ หรือมีคำถามใดๆ โปรดเขียนมาที่ ipe.haven@gmail.com เนื่องจากแอปและเว็บไซต์ไม่เก็บข้อมูลส่วนบุคคล โดยปกติเราจึงไม่มีข้อมูลที่ต้องค้นหา ส่วนอีเมลที่ติดต่อกันนั้น เราสามารถค้นหาและลบได้

5. เด็ก

แอปไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 16 ปี (หรือต่ำกว่าอายุขั้นต่ำในภูมิภาคของคุณ) และแอปไม่เก็บข้อมูลส่วนบุคคลจากผู้ใช้คนใดเลย

8. การเปลี่ยนแปลง

หากแอปหรือเว็บไซต์เพิ่มบัญชีหรือฟีเจอร์ออนไลน์ในภายหลังจนทำให้ข้อมูลที่เก็บเปลี่ยนไป เราจะอัปเดตนโยบายนี้ก่อนและเปลี่ยนวันที่มีผลบังคับใช้
